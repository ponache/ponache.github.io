# Portfolio — Николай Щекочихин

Персональный сайт-портфолио продуктового дизайнера. **Читай этот файл первым** — здесь всё, что нужно, чтобы не сканировать проект заново.

## Что это
Статический сайт: чистый HTML + CSS + ванильный JS. **Нет** сборки, фреймворков и зависимостей. Правишь файл → обновляешь браузер. Превью: `open index.html`.

## Правила
- Держим проект **без зависимостей и без сборки**. Не тащим npm/фреймворки.
- Стиль кода: отступ 2 пробела; комментарии часто на русском — сохраняй тон.
- Все стили — в `styles.css` через CSS-переменные из `:root` (акцент `--brand: #656AED`, скругления, easing `--t-fast`/`--t-slow`). Не хардкодь значения, если есть токен.
- Двуязычность RU/EN: у каждого переводимого узла атрибуты `data-ru` / `data-en`; атрибуты (href и т.п.) локализуются через `data-ru-<attr>` / `data-en-<attr>`. Язык по умолчанию — EN, хранится в localStorage `portfolio-lang`.
- Шрифты: системный SF Pro → Inter (Google Fonts) как фолбэк.
- Ключевые брейкпоинты: **760px** (хедер/мобилка), **720px** (info-строки), **640px** (модалка → нижний шит), **600px** (лента → 1 колонка).
- Стейты нажатия кастомные (`:active`: scale + лёгкое затемнение текста). Дефолтная мобильная подсветка тапа отключена глобально (`-webkit-tap-highlight-color: transparent`) — не возвращай её.

## Карточки кейсов — система `.ccard` (актуальная, блок CASE CARDS v2 в `styles.css`)
Контент кейса собирается из карточек в сетке `.case-flow` (2 колонки; на ≤760px — 1 колонка). **Одна карточка = опциональный текст сверху + одна картинка на сером фоне.** Аспект карточки задаёт **сама картинка** (прозрачный PNG/webp со своим внутренним отступом; `img { width:100%; height:auto }`) — отдельных классов аспекта (`sq`/`16x9`) в разметке нет, они только в имени файла.

Классы (комбинируются):
| Класс | Что |
|-------|-----|
| `.ccard` | половина ширины: текст (`.ct` → `h3` + `p`) + картинка (`.cm` → `img`) на сером |
| `+.full` | на всю ширину сетки (`grid-column: span 2`) |
| `+.fill` | **без текста** — картинка на всю карточку, край в край (обложка) |
| `+.dark` | тёмная карточка |

Обложка кейса — первая карточка `.ccard.fill.full` с `img/01-cover-wide.webp` (16:9, без текста). Серый фон под прозрачными PNG задаётся в CSS, не в картинке. У каждой карточки — класс `.reveal` (scroll-reveal из `main.js`).

**Имена картинок** — файлы в `projects/<slug>/img/`, по порядку сверху-вниз: `01-cover-wide.webp` (обложка), дальше `NN-sq.webp` (квадрат 1:1) / `NN-16x9.webp` (16:9), опц. суффикс `-dark`. Николай отдаёт картинки прозрачными PNG/webp, названными по порядку (`6.1`, `6.2`…) — переименовать под конвенцию и разложить по папкам.

**Сквозная навигация** внизу кейса (`.next` → `.next-cover`) показывает обложку **следующего** проекта: `../<next-slug>/img/01-cover-wide.webp`, кроп `aspect-ratio:16/9`. Цепочка: discounts-and-growth → order-and-support → international-mechanics → platform-news → platform-companies → internal-projects → (по кругу). Т.е. 16:9 обложка каждого кейса используется и в `img/`, и в нижней навигации предыдущего — единый источник. Главная (`index.html`) тянет отдельные обложки 4x5/4x3 из `assets/covers/` — их не трогаем.

**Резюме** — `assets/cv/Nikolai-Shchekochikhin-CV.pdf`, ссылка «CV/Резюме» в блоке «Контакты» (index + about), открывается в новой вкладке. Обновление — заменить файл с тем же именем.

_Legacy: старая система `.feature-card` (типы cover/png/fill, `.media-only`/`.overlay`/`.span2`, container-queries) ещё живёт в не-мигрированных кейсах — постепенно заменяется на `.ccard`. Мигрированы: `internal-projects`, `platform-news`, `platform-companies`; остальные 3 — на старой системе до наполнения контентом._

## Кэш стилей и скриптов
`styles.css` и `main.js` подключены с версией: `styles.css?v=3`, `main.js?v=3`. **Правишь CSS/JS — бампи число во всех HTML** (`index`, `about`, `project-template`, все `projects/*/index.html`), иначе мобильные браузеры (особенно iOS Safari, где нет жёсткой перезагрузки) продолжат отдавать старый файл и правки «не применятся».

## Замок на карточках главной (не опубликованные кейсы)
Плитки непубликованных проектов на `index.html` **заперты**: у `<a class="feed-item">` убран `href` и добавлен класс `.locked` (+ `aria-disabled`, локализованный `title` «Скоро»/«Coming soon»). Внутри `.feed-cover` лежит `<span class="lock">` с инлайн-SVG замка (`assets/`-исходник — `lockCloseEatsFill.svg`, но в разметке путь `fill:currentColor`, цвет белый). Стили — блок «Locked tiles» в `styles.css`: иконка 36×36 (моб. ≤600px — 24×24), отступ 24px (моб. 16px), hover-зум и press-скейл выключены. Затемнение — `.feed-cover::after`: большой радиальный градиент из левого-верхнего уголка (`circle at top left`, ~210px / моб. 140px), с одинаковой `mask-image` и `backdrop-filter: blur(2px)`, так что затемнение угла и блюр фона плавно угасают к центру. Крутилки: непрозрачность `rgba(0,0,0,.5)`, растекание `70%` в градиенте и маске, матовость `blur(2px)`. Заперты сейчас: `discounts-and-growth`, `order-and-support`, `international-mechanics`. Готовы (кликабельны): `platform-news`, `platform-companies`, `internal-projects`.

**Открыть проект:** вернуть `href="projects/<slug>/index.html"`, снять класс `.locked` и атрибуты `aria-disabled`/`title`/`data-*-title`, удалить `<span class="lock">…`. Запираем **только на главной** — сквозную навигацию `.next` внутри кейсов не трогаем.

## Модалка наград (index + about)
- Кнопки `[data-modal-open="aw-1|aw-2|aw-3"]` открывают `.modal-overlay#aw-x`.
- **Десктоп**: карточка справа-сверху, появляется плавно **без движения** (только opacity), клик по любому месту закрывает.
- **Мобилка (≤640px)**: нижний шит, свайп вниз **за любую область** шита закрывает (логика в `initModal` → `touchstart/move/end`).
